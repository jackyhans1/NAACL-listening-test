음성 청취 평가

두 개의 녹음을 듣고, 평가 음성이 기준 화자와 같은 사람처럼 들리는지와 얼마나 자연스러운지를 각각 1–5점으로 평가해 주세요.

  • 소요 시간: 약 30–45분 (중간에 짧은 휴식 2번)
  • 조용한 곳에서 이어폰 또는 헤드폰을 사용해 주세요. PC·노트북을 권장합니다.
  • 진행 상황은 이 브라우저에 자동 저장됩니다. 중간에 창을 닫아도 같은 평가자 ID·그룹으로 다시 시작하면 이어서 할 수 있습니다.
  • 모두 마치면 점수 CSV 파일을 내려받아 연구자에게 보내 주세요.

평가 과제 안내

한 화면에 녹음이 두 개 있습니다.

① 기준 음성

어떤 사람의 실제 녹음입니다. 이 사람의 목소리를 기억해 주세요.

② 평가 음성

점수를 매길 녹음입니다. 컴퓨터로 만들어진 음성일 수도 있습니다.

녹음은 모두 영어입니다. 말의 내용을 이해할 필요는 없으며, 두 녹음은 보통 서로 다른 문장을 말합니다. 단어나 내용은 평가 대상이 아닙니다.

평가 순서

  1. 조용한 환경에서 이어폰·헤드폰을 착용합니다. 시작하면 먼저 음량을 편한 크기로 맞춥니다.
  2. 기준 음성을 끝까지 듣습니다.
  3. 평가 음성을 끝까지 듣습니다. 두 녹음 모두 필요한 만큼 다시 들어도 됩니다.
  4. 아래 두 질문에 각각 답합니다. 두 녹음을 모두 끝까지 듣고 두 질문에 답해야 다음 버튼이 켜집니다.
  5. 처음 4개는 연습이며 점수에 포함되지 않습니다. 이어서 본 평가 54개가 나옵니다.

이미 답한 화면으로 되돌아가 점수를 바꿀 수는 없습니다. 각 화면을 독립적으로, 처음 든 인상대로 평가해 주세요.

질문별 판단 기준

질문 1. 화자 유사도

평가 음성이 기준 음성의 화자와 같은 사람의 목소리처럼 들리나요?

목소리 자체(음색, 음높이, 발성·말투의 특징)만 비교해 주세요. 무슨 단어를 말하는지, 녹음 음질이나 잡음은 무시합니다.

1분명히 다른 사람
2대체로 다른 사람
3잘 모르겠음 / 어느 정도 비슷함
4매우 비슷함
5같은 사람으로 들림

질문 2. 자연스러움

평가 음성이 사람의 말처럼 자연스럽게 들리나요?

잡음·왜곡, 끊김, 기계음 같은 느낌, 리듬의 매끄러움을 종합해 판단해 주세요. 누구의 목소리인지와는 따로 판단합니다.

1매우 부자연스러움
2부자연스러움
3보통
4자연스러움
5매우 자연스러움

핵심: 두 질문은 서로 독립적입니다. 예를 들어 아주 자연스럽지만 다른 사람 목소리일 수도 있고, 같은 사람처럼 들리지만 부자연스러울 수도 있습니다. 정답은 없으니 솔직한 인상대로 답해 주세요.
